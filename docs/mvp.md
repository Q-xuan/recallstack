# RecallStack MVP (v0.1.0)

## Goal

Deliver one end-to-end vertical slice:

1. Import a local repository
2. Scan with RepoWiki engine
3. Generate concepts + learning path
4. Answer an active-recall item with progressive hints
5. Receive rubric-based evaluation
6. Update mastery and FSRS schedule
7. Show due reviews on Dashboard

## Non-goals

Multi-user auth, payments, sandboxed code execution, bug injection, mobile apps, microservices.
